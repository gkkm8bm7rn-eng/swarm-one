# SWARM One v0.7.1 — Free PWA / iPhone First

Цель этой ветки: **0 обязательных платежей и 0 критических платных зависимостей**.

## Архитектура

- Основной интерфейс: Home Screen Web App на iPhone.
- App shell: статический HTML/CSS/JS, может хоститься бесплатно.
- Личные данные: IndexedDB на устройстве, не в репозитории.
- Контекст: Context Capsule + Context Gate.
- Рой: S0/S1/S2/S3, blind candidates до reveal, anonymous randomized comparison, Critic, Verifier, Repair, post-check, Judge.
- Резерв: Recovery Capsule (`.swarm`) — экспорт/импорт памяти, чатов, Ledger и настроек.
- Локальная модель: WebLLM + WebGPU. По умолчанию `Qwen2.5-0.5B-Instruct-q4f16_1-MLC` как осторожный мобильный старт.
- Облако, GitHub bot, email, OpenAI API: **не нужны для базовой работы** и не являются обязательными зависимостями.

## Почему 0.5B по умолчанию

В браузере iPhone важна не только скорость, но и GPU-memory. Большие модели могут завершать вкладку Safari из-за памяти. Поэтому v0.7.1 начинает с более лёгкой модели, а более сильные варианты включаются только после реального теста на целевом iPhone.

## Приватность публичного хостинга

Можно разместить код PWA в публичном GitHub Pages repository. Репозиторий содержит только код приложения. **Никогда не коммитьте** Context Capsule пользователя, Recovery Capsule, историю чатов, ключи или токены.

## Первый запуск

1. Открыть HTTPS-адрес PWA в Safari на iPhone.
2. Поделиться → На экран «Домой» → Open as Web App.
3. Открыть SWARM с Home Screen.
4. Настройки → Подготовить офлайн.
5. Дождаться полной загрузки модели.
6. Резерв → убедиться, что storage persistent или хотя бы проверить статус.
7. Полностью закрыть приложение, включить авиарежим и открыть снова.
8. Отправить короткую задачу. Только после этого считать устройство `Offline Ready`.

## Важные ограничения v0.7.1

- PWA storage устойчивее в Home Screen режиме, но это всё равно браузерное хранилище, не гарантия вечного хранения. Recovery Capsule обязателен как переносимый резерв.
- WebLLM-модель и библиотека впервые скачиваются из внешних источников. После загрузки веса кэшируются локально; реальный airplane-mode тест обязателен.
- PDF/OCR/Office/Vision инструменты из native v0.6 ещё не перенесены в эту PWA. v0.7.1 не притворяется, что умеет то, чего в ней нет.
- Большая часть интерфейса и памяти работает даже без модели; ответы в этом случае явно обозначаются как demo mode.

## Безопасность

- `localOnly = true` по умолчанию.
- Никаких API-ключей в клиентском коде.
- Никаких персональных данных в публичном репозитории.
- GitHub Pages — транспорт статического кода, а не память и не мозг роя.

## Что исправлено в v0.7.1

- Добавлены отсутствовавшие `app.js`, `styles.css`, `manifest.webmanifest`, `service-worker.js` и иконки.
- Реализованы локальная Context Capsule, Context Gate, Recovery Capsule, Ledger и локальный audit trace.
- Реализован SWARM-пайплайн S0–S3 с независимыми blind-кандидатами до reveal.
- WebLLM закреплён на версии `0.2.85`; базовая модель — `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`.
- В публичной сборке нет персонального Context Capsule, истории пользователя, Recovery Capsule, ключей или токенов.
